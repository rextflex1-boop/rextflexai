# Feature 2 — Gemini Multimodal + ImgBB/Bytescale

- Photos are uploaded to ImgBB and passed to the currently selected Gemini tier.
- Files use the Bytescale upload widget.
- Gemini model tiers: Apex = `gemini-3.8-flash`, Titan = `gemini-3.1-flash-lite`, Silicon = `gemini-2.5-flash`.
- The Gemini API is accessed through Google's OpenAI-compatible endpoint.
