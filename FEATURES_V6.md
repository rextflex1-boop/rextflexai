# RextFlex Ai v6

## Updated agent workspace

- Agent control moved into the chat keyboard.
- Agent model is fixed to Apex.
- Agent execution uses E2B when `E2B_API_KEY` is configured.
- Terminal output is background-only; chat renders concise file/build progress with check marks.
- Live project files remain available through the `+` menu.
- React/Vite projects are explicitly supported by the agent prompt.

## 3D Studio

- Image -> 3D
- Text -> 3D
- GLB preview
- Download GLB
- Import generated model into the current project

Set `MESHY_API_KEY` to enable the 3D generation endpoints.
